# Incremental SDD Specifications

The canonical implementation portfolio is maintained in the repository under [`specs/`](https://github.com/pulsaride/cdl-lang/tree/master/specs).

The roadmap owns strategic priority. Each increment owns a bounded implementation outcome, acceptance criteria, tasks, verification evidence and delivery status.

## First increments

1. **P0-001 — Compatibility Baseline:** preserve v0.6 behavior and establish tests.
2. **P0-002 — SIR v1 Contract:** versioned immutable semantic representation.
3. **P0-003 — Structured Typed Expressions:** typed nodes and expression-derived dependencies.
4. **P0-004 — Semantic Resolution and Validation:** deterministic V2 diagnostics.
5. **P0-005 — Dependency Graph:** stable semantic graph and cycle detection.
6. **P0-006 — Bounded Reference Evaluator:** optional V3 feasibility and scope.
7. **P0-007 — Semantic Diff and Impact:** deterministic change and transitive impact.
8. **P0-008 — Verification Traceability:** evidence, obligations and V1–V5 reporting.
9. **P0-009 — Developer Vertical Slice:** one executable author-to-impact workflow.

See the full [traceability matrix](https://github.com/pulsaride/cdl-lang/blob/master/specs/TRACEABILITY.md) and the [increment template](https://github.com/pulsaride/cdl-lang/blob/master/specs/templates/INCREMENT.md).
